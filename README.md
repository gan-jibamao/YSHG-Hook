# YSHG Hook

**阅姝阁**（`com.box.dxgxx44`）增强插件 —— 下载加速 · 记录面板 · 内置播放器。

> **闭源发布。** 本仓库只提供成品包与文档，**不含任何源代码**。
> 二进制已做常量段加密（ChaCha20）+ 符号表抹除。

作者 / 版权：**鸡巴毛**

---

## 功能

### 下载
| 能力 | 说明 |
|---|---|
| 自动嗅探 | 抓取 app 内 m3u8 播放请求，一键入库 |
| 多任务并行 | 最多 32 队列 · 6 路并发 |
| 段级并行 | 单任务分段并行抓取，按序自动拼合 |
| 连接复用 | 专用 NSURLSession · HTTP/2 |
| 代理回退 | 直连失败走 app 本地代理 127.0.0.1:6001-6005 |
| AES-128 解密 | 支持 HLS 加密流（EXT-X-KEY） |
| TS → MP4 | 内置纯 C 重封装器，无需外部工具 |
| 日志 | `Documents/yshg_net.log`，超 8MB 自动轮转 |

### 播放器
- 自绘控制层：渐变压暗 · 文件名 · 圆形关闭钮
- 可拖动进度条（双端时间）
- 播放/暂停 · **0.75× / 1× / 1.25× / 1.5× / 2×** 倍速（保持音调）
- 音量滑杆
- 点画面切换控制层 · 播放 3 秒自动隐藏 · 暂停常显
- 横竖屏自适应

### 记录面板
- 双击悬浮钮呼出 · 卡片列表 · 状态徽标
- 点行播放 · **左滑删除**

## 安装

**① TrollFools（推荐）**：注入 `yshg_hook.dylib` → 重启 app

**② 越狱 deb**：
```
dpkg -i yshg_hook_4.14.0_iphoneos-arm64.deb
```

**③ 整包 IPA**：安装 `阅姝阁-hook-v4128.ipa`（已内置，需自签）

## 使用

| 操作 | 说明 |
|---|---|
| 单击悬浮钮 | 抓取当前 m3u8 |
| 双击悬浮钮 | 打开 / 关闭记录面板 |
| 点记录行 | 播放文件 |
| 左滑记录行 | 露出删除按钮 |
| 播放中点画面 | 显示 / 隐藏控制层 |

下载目录 `Documents/yshg_dl/` · 日志 `Documents/yshg_net.log`
